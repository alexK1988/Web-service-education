# ВКР на тему "Разработка web-сервиса для системы управления образовательным процессом на базе 1С:Предприятие

## Описание проекта

Проект представляет собой конфигурацию на платформе 1С:Предприятие, предназначенную для автоматизации основных процессов образовательной организации.

В системе реализованы справочники, документы, регистры, отчёты, роли пользователей, бизнес-процессы, задачи пользователя, а также HTTP-сервис для предоставления данных внешним информационным системам через Web API.

## Цель проекта

Целью проекта является разработка информационной системы управления образовательным процессом с возможностью интеграции с внешними сервисами посредством HTTP API.

## Основные возможности

- ведение нормативно-справочной информации;
- учёт студентов, преподавателей, учебных групп и дисциплин;
- формирование расписания занятий;
- учёт успеваемости студентов;
- учёт посещаемости занятий;
- расчёт учебной нагрузки преподавателей;
- формирование отчётов;
- загрузка и очистка тестовых данных;
- проверка заполнения тестовых данных;
- работа с задачами пользователя;
- предоставление данных через HTTP-сервис;
- логирование вызовов Web API.

## Структура конфигурации

### Справочники

В конфигурации реализованы справочники:

- Организации
- Подразделения
- Учебные группы
- Студенты
- Кафедры
- Преподаватели
- Дисциплины
- Виды занятий
- Учебные периоды
- Направления подготовки
- Учебные планы
- Формы обучения
- Аудитории
- Внешние системы
- Причины отсутствия

Часть справочников является иерархической, что позволяет хранить данные в структурированном виде.

### Документы

В системе реализованы документы:

- Приказ о зачислении
- Приказ о переводе
- Приказ об отчислении
- Назначение преподавателя
- Формирование расписания
- Занятие
- Ведомость оценок
- Посещение занятия
- Корректировка учебного плана
- Обращение студента

Документы используются для отражения операций учебного процесса и формирования движений по регистрам.

### Регистры сведений

Реализованы регистры сведений:

- Состав учебных групп
- Закрепление дисциплин за преподавателями
- Расписание занятий
- Параметры учебного плана
- Настройки доступа API
- История вызовов API

### Регистры накопления

Реализованы регистры накопления:

- Успеваемость студентов
- Посещаемость студентов
- Учебная нагрузка преподавателей

### Отчёты

В конфигурации разработаны отчёты:

- Расписание группы
- Успеваемость студента
- Посещаемость группы
- Нагрузка преподавателя
- Сводный отчёт по группе

Отчёты позволяют анализировать данные учебного процесса на основании сведений, накопленных в регистрах.

## Web API

В проекте реализован HTTP-сервис `EducationAPI`.

Доступные методы:

- `/status` — проверка состояния сервиса;
- `/students` — получение списка студентов;
- `/groups` — получение списка учебных групп;
- `/teachers` — получение списка преподавателей;
- `/disciplines` — получение списка дисциплин;
- `/schedule` — получение расписания занятий.

**Пример адреса локального вызова:**
http://localhost/Education_Process/hs/education/status

**Пример ответа метода /status:**
{
  "service": "EducationAPI",
  "status": "running",
  "version": "1.0",
  "description": "Web-сервис системы управления образовательным процессом"
}
